# Read the Room website

The home page for **Read the Room**, a cozy pixel-art room design game for Android.

Plain HTML and CSS with no build step. GitHub Pages serves the `main` branch as-is.

- `index.html`: home page
- `privacy.html`: privacy policy (linked from Google Play)
- `app-ads.txt`: AdMob authorised sellers file, served at the site root
- `img/`: screenshots, icon and social preview image
